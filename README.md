# TESSEN

Адаптивный сайт портфолио независимой студии. В проекте восемь страниц на трёх языках: русская версия на основных адресах, английская в `/en/` и китайская (упрощённая) в `/zh/`. Переключатель языка в шапке сохраняет текущую страницу.

## Запуск

```sh
npm ci
npm run dev
```

Локальный адрес: `http://127.0.0.1:4173/`. Генерация изображений и favicon использует системную утилиту `sips` в macOS. Исходные материалы остаются в `Assets/`, фирменные знак и словесный логотип — в `Assets/Logo/`, облегчённые версии изображений создаются в `media/`, готовый сайт — в `dist/`.

## Кинетический логотип

Первые экраны внутренних страниц используют `kinetic-logo.js`: объёмная геометрия строится из заполненных контуров `Assets/Logo/fan.svg`. Цикл длится 24 секунды; движения рассчитываются из общей периодической фазы. Размах разборки задаётся для каждой страницы в `intensity`, положение и затемнение — стилями `.kinetic-scene`.

Three.js закреплён в `package-lock.json` и копируется сборкой в `dist/vendor/three/` вместе с лицензией. Сайт загружает библиотеку со своего хостинга. Анимация останавливается вне экрана и в скрытой вкладке. При уменьшении движения отображается статичная 3D-сцена, при недоступности WebGL или модуля — SVG. Главная страница не загружает модуль сцены.

## Публикация

Публикуйте папку `dist/` как статический сайт после `npm run build`. На хостинге включите маршрутизацию директорий на `index.html`.

Когда будет выбран домен, соберите сайт с `SITE_URL=https://your-domain.example npm run build`. Это добавит canonical URL и создаст `sitemap.xml` с абсолютными адресами. Пока домен не выбран, генератор не записывает вымышленный адрес.

Русский исходный контент и структура страниц редактируются в `site.mjs`, английский и китайский тексты — в `translations.tsv`. Каждая строка словаря содержит исходный текст, английский и китайский перевод через табуляцию. Генератор требует перевода для каждой русской строки, включая метаданные. Общие стили — в `style.css`, интерактивные элементы — в `app.js`. Контактный адрес сейчас: `martynov.e1982@gmail.com`.

`npm run check` проверяет синтаксис JavaScript, наличие страниц и внутренние ссылки.
